# cv-starter

A starter for a PDF CV built with Quarto and Typst, used in POLS 6394 at the University of Houston.

This is a fork of Christopher T. Kenny's [`quarto-cv`](https://github.com/christopherkenny/quarto-cv) template (MIT license). The layout, shortcodes, citation styles, and sample entries are his. This fork:

- renames the document to `cv.qmd` and adds `cv.Rproj`, so it opens as an RStudio project;
- adds a Working Papers section and `working_papers.bib`;
- removes the Appointments section and the template's instructions, which are in the original repository.

## Use it

On this page, choose **Use this template → Create a new repository**, name it `cv`, and make it private. Then, in RStudio, choose **File → New Project → Version Control → Git**, paste your new repository's URL, and create the project.

Edit `cv.qmd`, the `.yaml` files, and the `.bib` files, then click **Render**. See Kenny's README for every shortcode and option.
